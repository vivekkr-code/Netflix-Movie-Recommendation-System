# 🎬 Netflix Movie Recommendation System

## 📌 Project Overview

This project recommends movies available in a Netflix titles dataset based on similarities in their genres, cast, directors, and descriptions. It uses Natural Language Processing (NLP) techniques and machine learning tools from Scikit-learn.

## 🎯 Objectives

* Explore and clean Netflix movie data.
* Analyze movie genres and descriptions.
* Build a content-based movie recommendation engine.
* Recommend similar movies using cosine similarity.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

## ⚙️ Machine Learning Techniques

* TF-IDF Vectorization
* Cosine Similarity
* Content-Based Filtering

## 📂 Dataset

The project uses a Netflix titles dataset containing information such as titles, directors, cast, genres, release years, and descriptions.

## 🚀 How to Run

1. Download or clone this repository.
2. Open `Netflix_Movie_Recommendation_System.ipynb` in Google Colab or Jupyter Notebook.
3. Upload `netflix_data.csv` to the notebook environment.
4. Run the notebook cells in order.
5. Use the recommendation function to find similar movies.

## 💡 Example

```python
recommend_movies("The Conjuring")
```

The function returns movies with similar content when the requested title is available in the dataset.

## 📈 Key Learning Outcomes

* Data cleaning and exploratory data analysis.
* Text preprocessing and feature extraction.
* Building a content-based recommendation system.
* Applying Scikit-learn to a real-world dataset.
